# 🚀 NordX-Pro | Advanced SOCKS5 Manager

<div dir="rtl">

**NordX-Pro** یک ابزار اتوماسیون پیشرفته و یکپارچه برای مدیریت تونل‌های NordVPN و تبدیل آن‌ها به پراکسی‌های مستقل SOCKS5 روی سرورهای لینوکسی است[cite: 18]. 

**کاربرد اصلی:** با استفاده از تنها یک اکانت معتبر NordVPN، این اسکریپت به شما اجازه می‌دهد چندین نود (تونل) مستقل و پایدار را روی یک سرور مجازی ایجاد کنید. هر تونل به یک پورت SOCKS5 داخلی (Localhost) متصل می‌شود. تعداد تونل‌های همزمان به محدودیت‌های اتصال اکانت نورد شما و منابع سرور بستگی دارد. این معماری برای یکپارچه‌سازی با پنل‌های مدیریت ترافیک (مثل X-UI یا HAProxy) و دور زدن تحریم‌ها در زیرساخت‌های داده حرفه‌ای فوق‌العاده کاربردی است[cite: 18].

در این نسخه، معماری فایل‌های استاتیک به طور کامل کنار گذاشته شده است[cite: 18]. nordx به صورت **داینامیک** کانفیگ‌ها را می‌سازد، نودها را مدیریت می‌کند و با یک منوی تعاملی قدرتمند، کنترل کامل ترافیک و سرورها را در اختیار شما قرار می‌دهد[cite: 18].

## ✨ امکانات و قابلیت‌های کلیدی

- ⚡ **معماری کاملاً داینامیک:** ساخت و ویرایش خودکار فایل‌های Docker Compose در لحظه بدون نیاز به دستکاری دستی[cite: 18].
- 🌍 **مدیریت تعاملی و هوشمند:** دریافت زنده لیست کشورهای فعال از API نورد، تولید خودکار شناسه نود و مدیریت نودهای تکراری.
- 🎯 **دسترسی سراسری (Global Command):** فراخوانی منوی مدیریت از هر کجای ترمینال فقط با تایپ یک کلمه (`nordx`)[cite: 18].
- ✏️ **ویرایش زنده:** قابلیت تغییر پورت SOCKS5 یک نود فعال بدون نیاز به حذف و نصب مجدد آن.
- 🛡️ **احراز هویت SOCKS5:** پشتیبانی از تنظیم نام کاربری و رمز عبور اختصاصی برای پراکسی‌های خروجی[cite: 18].
- 📡 **تستر هوشمند شبکه:** بررسی سلامت نود پیش از ثبت نهایی، نمایش آی‌پی واقعی، نام کشور، سرویس‌دهنده (ISP) و محاسبه پینگ (Latency) به صورت زنده[cite: 18].
- 🛠 **سیستم خودترمیم (Auto-Repair):** اسکن و فیلتر سخت‌گیرانه فایل تنظیمات برای جلوگیری از کرش کردن ترمینال به دلیل فاصله‌های غیرمجاز.
- 🔄 **آپدیت امن:** به‌روزرسانی مستقیم از گیت‌هاب بدون از دست رفتن تنظیمات و اطلاعات کاربری ذخیره شده[cite: 18].
