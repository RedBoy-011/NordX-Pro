# 🚀 NordX-Pro | Advanced SOCKS5 Manager

<div dir="rtl">

**NordX-Pro** یک ابزار اتوماسیون پیشرفته و یکپارچه برای مدیریت تونل‌های NordVPN و تبدیل آن‌ها به پراکسی‌های مستقل SOCKS5 روی سرورهای لینوکسی است. 

در این نسخه، معماری فایل‌های استاتیک به طور کامل کنار گذاشته شده است. nordx به صورت **داینامیک** کانفیگ‌ها را می‌سازد، نودها را مدیریت می‌کند و با یک منوی تعاملی قدرتمند، کنترل کامل ترافیک و سرورها را در اختیار شما قرار می‌دهد. ایده‌آل برای یکپارچه‌سازی با پنل‌های مدیریت ترافیک و زیرساخت‌های داده حرفه‌ای.

---

## ✨ قابلیت‌های کلیدی

- ⚡ **معماری داینامیک:** ساخت خودکار فایل‌های Docker Compose در لحظه (بدون نیاز به ویرایش دستی فایل‌ها).
- 🌍 **مدیریت تعاملی نودها:** اضافه یا حذف کردن تونل کشورهای مختلف تنها با چند کلیک در منو.
- 🎯 **دسترسی سراسری (Global Command):** فراخوانی منوی مدیریت از هر کجای ترمینال فقط با تایپ یک کلمه (`nordx`).
- 🛡️ **احراز هویت SOCKS5:** پشتیبانی از تنظیم نام کاربری و رمز عبور اختصاصی برای پراکسی‌های خروجی.
- 📡 **تستر هوشمند شبکه:** بررسی سلامت نود، نمایش آی‌پی واقعی، نام کشور، سرویس‌دهنده (ISP) و محاسبه پینگ (Latency) به صورت زنده.
- 🔄 **آپدیت امن:** به‌روزرسانی مستقیم از گیت‌هاب بدون از دست رفتن تنظیمات و اطلاعات کاربری ذخیره شده.
- 🧹 **پاک‌سازی هوشمند:** متوقف‌سازی و حذف خودکار کانتینرهای منسوخ‌شده (Orphans) هنگام تغییر نودها.
